Herramientas desarrolladas en Python

Desarrollo herramientas personalizadas para eliminar cuellos de botella en la producción de contenido: desde procesadores de archivos y organizadores de recursos hasta interfaces gráficas locales.

Interfaces limpias (PyWebView / Tkinter) Automatización de archivos & renders Scripts de consumo de APIs externas
automation_tool.py Python 3.11 
# Herramienta de automatización de workflow audiovisual
import os
import pywebview

class WorkflowAutomation:
    def organize_assets(self, project_path):
        folders = ["01_RAW", "02_AUDIO", "03_GRAPHICS", "04_EXPORTS"]
        for folder in folders:
            os.makedirs(os.path.join(project_path, folder), exist_ok=True)
        return "Estructura lista."

# Iniciando interfaz nativa
if __name__ == '__main__':
    api = WorkflowAutomation()
    webview.create_window('Automation Hub', html='<h1>Procesador</h1>', js_api=api)
    webview.start()
