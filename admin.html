¿Cómo creo el token? (una sola vez, 2 minutos)
  1. GitHub → tu avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories y selecciona el repo del portafolio.
  3. En Permissions → Repository permissions busca Contents y ponlo en Read and write.
  4. Genera el token, cópialo y pégalo arriba. Queda guardado solo en este navegador.
